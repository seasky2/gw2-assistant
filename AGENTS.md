# gw2-assistant

Read-only MCP server (Python, stdio) over a Guild Wars 2 account.
Code, comments, messages and docs in English; reply to the user in their
own language, short and direct.

## Rules
- Read-only; never invent data — if a call fails, show the exact error.
- Tool policy: add a new tool only if it makes sense and is not redundant
  with an existing one — if redundant, absorb it as a helper or replace the
  old one (audit usage from time to time). crafting_cost left in v2.7 (became
  the _crafting_cost helper; item_craft_info covers it).
- GW2_API_KEY only via environment: never print, log, put it in a URL or in
  an error message (tests guarantee this).
- Routes, farm and craft: read the real inventory (account_bank,
  account_inventory, materials_with_names, account_wallet), check recipe and
  source on the Wiki (never from memory), subtract what the player already
  has and deliver the corrected result.

## Files
- gw2_server.py: server, 40 tools, VERSION 2.8. English names.
  diagnostics also reports key permissions (it replaced the old status tool;
  account_materials left — materials_with_names covers it). v2.8: left
  achievement_summary (progress_guide embeds the summary block with the same
  totals: records/completed/in_progress/no_progress_recorded). v2.7: entered
  raid_progress (raid clears per wing via account/raids; strikes and fractals
  have no progress endpoint — dailies live in daily_weekly_progress and
  wizards_vault); left crafting_cost (item_craft_info covers it; the logic
  became the _crafting_cost helper). v2.6: left item_price (item_info covers)
  and account_achievements (achievement_details gained include_progress);
  entered item_info (card + TP + wiki by id/name), recipes_using (who uses
  the item, legendary first), craft_profit (real craft-to-sell ranking),
  bank_cleanup (bank verdict) and legendary_route (step-by-step route; API
  recipe → Wiki {{recipe}} → leaf). v2.5: find_craftable (what can be crafted
  right now with bank + materials), character_crafting (disciplines per
  character), tp_listings (TP book depth).
- gw2_items_index.json: name→id index of all items (generated by the first
  tool that resolves a name — item_info, recipes_using, legendary_route etc.
  —, regenerated every 7 days).
- gw2_recipes_cache.json: full recipe catalog (~13k, generated by
  find_craftable, same 7-day TTL; base for recipes_using, craft_profit and
  bank_cleanup).
- test_gw2_server.py: tests with mocked API — `.venv\Scripts\python.exe -m
  unittest test_gw2_server` (OK goes to stderr; 149 tests).
- verify_api.py: runs every tool with the real key (save_snapshot left out on
  purpose; 39 entries). Last validation 2026-10-17: 38 OK, 1 warning
  (compare_progress without snapshot), 0 failures.

## Environment
- Windows, Python 3.14, project .venv (requests, tzdata, mcp 1.x/2.x).
- Default timezone used by the tools: America/Sao_Paulo (UTC-03:00), passed
  as a parameter where relevant.
- After editing gw2_server.py: reload the MCP server (in OpenCode:
  `/mcps` → disconnect/connect — the service keeps the process alive,
  without this the session keeps the old tool list).

## Known limits and gotchas
- Wiki: api.php requires a User-Agent with a browser prefix (otherwise nginx
  answers 403) and the /w/api.php path is blocked — the server uses WIKI_UA +
  /api.php, so search_wiki and wiki_details work (text cleaned via extracts).
  The raw wikitext fallback is rare now; a web fetch still helps with messy
  vendor/chest tables.
- `/v2/items` and `/v2/recipes` reject ids=all (400); legendaryarmory and
  achievements/categories accept — the item index fetches ids in batches of
  200 (resolve_names too). Recipes only paginate (page=N, 50 COMPLETE recipes
  per page, ~265 pages): the invalid-page error carries the total
  ("page values 0 - 264") — find_craftable uses that + parallelism + disk.
- Prices: item_prices uses buy=bid / sell=ask; item_info and item_craft_info
  use the `_now` suffix = act now (tp_buy_now = lowest ask, what you pay;
  tp_sell_now = highest bid, what you receive; buy_total_now = ask × quantity).
- Legendaries: gifts and precursor live in account_bank; T6 materials in
  materials_with_names; shards/karma/currencies in account_wallet.
- Key permissions: account, wallet, progression, inventories, characters,
  unlocks, tradingpost, pvp, wvw, builds, guilds.
- Public `sort_by` values (progress_guide, action_plan) are English since v2.8:
  percent | remaining | points | points_per_unit (older pt-BR values such as
  percentual/faltam/pontos are rejected with a clear error listing the valid
  ones).
- compare_progress ignores the old gw2_history.jsonl entry (2026-10-13, old
  schema): run save_snapshot before using it.
